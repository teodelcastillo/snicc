## 1. Introducción

El **SNICC** (Sistema Nacional de Información sobre Cambio Climático) es una plataforma web diseñada para centralizar, gestionar y difundir información sobre cambio climático en Argentina. A través de ella se puede:

- **Publicar y consultar novedades** sobre cambio climático.
- **Acceder a una biblioteca** de documentos, informes e infografías.
- **Consultar normativas** vigentes (leyes, decretos, resoluciones).
- **Visualizar planes de respuesta** de cada provincia en un mapa interactivo.
- **Dar seguimiento a medidas climáticas nacionales**, incluyendo su estado de implementación, metas anuales y estadísticas.
- **Exportar información** en formato PDF y CSV.
- **Monitorear y evaluar** el avance de las medidas a través del módulo MYE.

La plataforma está pensada para distintos tipos de usuarios: desde el público general que consulta información, hasta administradores y coordinadores de contenido que gestionan las publicaciones y medidas.

Este manual está dirigido principalmente a **administradores** y **coordinadores de contenido**, y explica paso a paso cómo aprovechar todas las capacidades del sistema.

## 2. Primeros pasos

### 2.1 Registro en la plataforma

Cualquier persona puede registrarse en el SNICC para personalizar su experiencia. El proceso requiere definir una **contraseña personal**, que luego se utilizará para iniciar sesión:

1. Desde la página de inicio, hacer clic en **"Iniciar sesión"** o **"Registrarse"**.
2. Completar el formulario de registro con los siguientes datos:
   - **Nombre** y **Apellido**
   - **País** (Argentina seleccionado por defecto)
   - **Provincia** (obligatorio si el país es Argentina)
   - **Ciudad**
   - **Género**
   - **Correo electrónico** (será el identificador para ingresar)
   - **Teléfono** (opcional)
   - **Contraseña** y **Confirmación de contraseña**
3. Hacer clic en **"Registrarse"**.
4. Si los datos son válidos, la cuenta se crea y el usuario queda autenticado automáticamente.
5. A continuación, se mostrará una pantalla para seleccionar el **perfil temático** de interés (Adaptación, Mitigación, Bosques, etc.). Esto permite personalizar el contenido recomendado.

> **Nota:** La contraseña es personal e intransferible. Se recomienda elegir una combinación que no sea fácil de adivinar y no reutilizar contraseñas de otros servicios.

### 2.2 Inicio de sesión

El SNICC utiliza un sistema clásico de autenticación mediante **correo electrónico y contraseña**:

1. Hacer clic en **"Iniciar sesión"** desde la barra superior.
2. Ingresar el **correo electrónico** registrado y la **contraseña** definida en el registro.
3. Hacer clic en **"Ingresar"**.
4. Si las credenciales son correctas, se accederá a la plataforma con todas las funcionalidades disponibles según el rol del usuario.

> **Importante:** Si se produce un error de credenciales, verificar que el correo esté correctamente escrito (sin espacios ni errores tipográficos) y que la contraseña sea la correcta.

### 2.3 Gestión de perfil personal

Una vez autenticado, cada usuario puede gestionar su información personal:

1. Hacer clic en el botón de **perfil** en la barra superior (generalmente aparece como el nombre del usuario o un ícono de persona).
2. En la pantalla de perfil se puede modificar:
   - Nombre y apellido
   - País, provincia y ciudad
   - Género
   - Teléfono
   - **Perfil temático** (se puede cambiar en cualquier momento)
3. El correo electrónico **no se puede modificar** desde esta pantalla, ya que es el identificador único de la cuenta.
4. Hacer clic en **"Guardar"** para aplicar los cambios.

## 3. Roles y permisos

La plataforma maneja distintos niveles de acceso. Cada usuario puede tener uno o más roles según sus responsabilidades:

| Rol | Descripción | Acceso principal |
|-----|-------------|-----------------|
| **Usuario registrado** | Persona que se registra en el portal para consultar información. | Contenido público, perfil personal. |
| **Editor / Redactor** | Responsable de crear, editar y traducir publicaciones. Puede también editar medidas si tiene el permiso correspondiente. | Panel de gestión de contenido. |
| **Administrador (Staff)** | Gestiona la configuración de la plataforma: usuarios, categorías, biblioteca, normativas, medidas. | Panel de administración. |
| **Superusuario** | Acceso completo al sistema, incluyendo la creación y eliminación de otros usuarios y administradores. | Todo el sistema. |

| Gestionar perfil personal | Si | Si | Si | Si |
| Crear publicaciones | — | Si (*) | Si | Si |
| Editar publicaciones | — | Si (*) | Si | Si |
| Traducir publicaciones | — | Si (*) | Si | Si |

## 4. Navegación general de la plataforma

### 4.1 Página de inicio

La página de inicio es el punto de entrada al SNICC y presenta:

- **Descripción general** del Sistema Nacional de Información sobre Cambio Climático.
- **Tres pilares principales**: Mitigación, Adaptación, y Pérdidas y Daños, con acceso directo a cada sección.
- **Barra de búsqueda** para encontrar contenido rápidamente.
- **Últimas novedades**: las 3 noticias más recientes publicadas en la plataforma.
- **Accesos directos** a recursos destacados: SIMARCC, INGEI, Monitoreo de Medidas Climáticas, Planes de Respuesta.
- **Invitación a registrarse** (para usuarios no autenticados).

### 4.2 Barra de navegación superior

Ubicada en la parte superior de todas las páginas, contiene:

- **Selector de idioma**: permite cambiar el idioma de la interfaz y el contenido (si hay traducciones disponibles).
- **Barra de búsqueda**: para buscar contenido en todo el sitio.
- **Botón de accesibilidad**: despliega las herramientas de accesibilidad.
- **Inicio de sesión / Perfil**: botón para iniciar sesión o acceder al perfil.
- **"Gestión de contenido"**: visible solo para editores, da acceso al panel de edición.
- **"Admin"**: visible solo para administradores, da acceso al panel de administración.

### 4.3 Menú lateral

El menú lateral izquierdo permite navegar por las secciones principales del sitio:

- **Inicio**: vuelve a la página principal.
- **Gestión climática**: páginas de contenido sobre gestión del cambio climático.
- **Monitoreo (MYE)**: acceso al módulo de Monitoreo y Evaluación.
- **Normativas**: listado de leyes, decretos y resoluciones.
- **Biblioteca**: catálogo de documentos y publicaciones.
- **Novedades**: noticias y artículos recientes.
- **Enlaces de interés**: recursos externos relevantes.
- **Cerrar sesión**: cierra la sesión del usuario (solo visible si está autenticado).

### 4.4 Herramientas de accesibilidad

La plataforma incluye un conjunto de herramientas de accesibilidad que se activan desde la barra superior. Estas opciones permiten adaptar la experiencia de navegación a diferentes necesidades:

| Herramienta | Descripción |
|-------------|-------------|
| **Escala de grises** | Convierte toda la interfaz a tonos de gris, reduciendo la estimulación visual. |
| **Tamaño del cursor** | Aumenta el tamaño del cursor para facilitar su localización. |
| **Tipografía para dislexia** | Cambia la fuente tipográfica a una diseñada para facilitar la lectura a personas con dislexia. |
| **Contraste** | Aumenta el contraste de colores para mejorar la legibilidad. |
| **Resaltar enlaces** | Destaca visualmente todos los enlaces de la página. |
| **Máscara de lectura** | Aplica una máscara que oscurece el contenido excepto la línea que se está leyendo. |
| **Guía de lectura** | Muestra una línea guía horizontal que sigue el cursor para facilitar la lectura. |
| **Lector de pantalla** | Activa compatibilidad con lectores de pantalla. |
| **Restablecer** | Devuelve todas las opciones de accesibilidad a sus valores por defecto. |

## 5. Contenido público: Consulta de información

### 5.1 Novedades

La sección de **Novedades** presenta las últimas noticias y artículos publicados sobre cambio climático.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Novedades"**.

**Funcionalidades disponibles:**
- **Visualizar noticias** en formato de tarjetas con imagen, título, fecha y categoría.
- **Filtrar por categoría** usando el panel lateral de filtros.
- **Navegar entre páginas** con la paginación en la parte inferior (8 noticias por página).
- **Leer el artículo completo** haciendo clic en la tarjeta de la noticia.

**Dentro de un artículo se puede:**
- Ver la **tabla de contenidos** generada automáticamente a partir de los títulos y secciones.
- Acceder a **contenido relacionado** (publicaciones hijas, enlaces internos).
- **Compartir el artículo** a través de los botones de redes sociales.
- Navegar mediante las **migas de pan** (breadcrumbs) en la parte superior.

### 5.2 Biblioteca

La **Biblioteca** es un catálogo de documentos, informes, infografías y otros recursos descargables.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Biblioteca"**.

**Funcionalidades disponibles:**
- **Buscar** por autor, título o descripción usando la barra de búsqueda integrada.
- **Filtrar** los resultados por:
  - **Categoría** (Adaptación, Mitigación, etc.)
  - **Formato** (Documento PDF, Infografía, etc.)
  - **Autor** (se muestran los autores más frecuentes)
- **Ordenar** los resultados por:
  - Más recientes (por defecto)
  - Título (A–Z)
  - Autor (A–Z)
- **Ver detalles** de cada recurso, incluyendo título, autores, descripción y año de publicación.
- **Descargar** o acceder al documento haciendo clic en el enlace correspondiente.

### 5.3 Normativas

La sección de **Normativas** recopila las leyes, decretos, resoluciones y disposiciones administrativas vinculadas al cambio climático.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Normativas"**.

**Funcionalidades disponibles:**
- **Buscar** normativas por nombre o descripción.
- **Filtrar** por tipo de normativa:
  - Ley
  - Decreto
  - Resolución
  - Administrativo
- **Navegar** entre páginas (6 normativas por página).
- **Acceder al texto completo** de cada normativa a través de los enlaces provistos.

### 5.4 Planes de respuesta provinciales

Esta sección muestra un **mapa interactivo de Argentina** con información sobre los planes de respuesta al cambio climático de cada provincia.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Gestión climática"** y luego en **"Planes de respuesta"**, o desde los accesos directos de la página de inicio.

**Funcionalidades disponibles:**
- **Explorar el mapa**: hacer clic en una provincia para ver su información.
- **Ver el estado** del plan de cada provincia (indicadores visuales de progreso).
- **Consultar detalles**: autoridad responsable, plan de respuesta vigente, normativa provincial y datos de contacto.
- **Acceder a los documentos** del plan haciendo clic en los enlaces provistos.

### 5.5 Enlaces de interés

Sección que recopila enlaces a recursos externos relevantes sobre cambio climático.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Enlaces de interés"**.

**Funcionalidades disponibles:**
- **Explorar enlaces** organizados por categoría.
- **Filtrar** por categoría de interés.
- **Navegar** entre páginas (6 enlaces por página).
- **Acceder al recurso externo** haciendo clic en el enlace.

### 5.6 Buscador

La plataforma cuenta con un **buscador global** que permite encontrar contenido en todo el sitio.

**Cómo acceder:**
- Desde la **barra de búsqueda** en la parte superior de cualquier página.
- Desde la **barra de búsqueda** de la página de inicio.

**Funcionalidades disponibles:**
- **Buscar** por palabras clave en títulos y contenido de publicaciones.
- **Filtrar resultados** por categoría.
- **Navegar** entre páginas de resultados (6 resultados por página).
- **Acceder al contenido** haciendo clic en el resultado.

## 6. Medidas climáticas

### 6.1 Explorar medidas

Las medidas climáticas nacionales están organizadas en una estructura jerárquica:

- **Líneas estratégicas** (agrupadas en categorías)
  - **Líneas de acción** (acciones específicas dentro de cada línea)
    - **Medidas** (acciones concretas de implementación)

**Cómo acceder:**
Navegar al listado de medidas desde los accesos directos de la página de inicio o desde el menú de Monitoreo.

**Funcionalidades disponibles:**
- **Visualizar todas las medidas** organizadas por línea estratégica y línea de acción.
- **Filtrar medidas** por:
  - Línea estratégica
  - Línea de acción
  - Estado de implementación (En programación, En implementación, Completada, etc.)
  - Pilar (Adaptación, Mitigación, Pérdidas y Daños)
  - Alcance (Nacional, Regional)
- **Ver estadísticas** de implementación:
  - Gráficos de torta con distribución por estado
  - Gráficos de barras apilados por categoría
  - Distribución por pilar y línea

### 6.2 Detalle de una medida

Al seleccionar una medida, se accede a su ficha completa con toda la información disponible.

**Información que se puede consultar:**
- **Nombre y código** de la medida.
- **Estado de implementación** actual.
- **Pilar** al que pertenece (Adaptación, Mitigación, Pérdidas y Daños).
- **Línea estratégica** y **línea de acción** correspondientes.
- **Alcance geográfico** (Nacional / Regional / A definir). La tarjeta **"Alcance y estado"** muestra únicamente el valor del alcance (por ejemplo, Nacional), sin leyenda de fecha de actualización.
- **Campos descriptivos** dinámicos con información detallada de la medida.
- **Metas anuales**: objetivos establecidos para cada año.
- **Objetivos nacionales** asociados a la medida.

**Dónde se muestran las metas por año:**
- **Tarjeta "Metas por año"** (en la zona superior de la ficha): se muestra únicamente la **descripción breve** de cada meta anual. Si no hay descripción breve, solo se ve el año.
- **Información general → Metas / Años** (en la sección inferior): se muestra la **descripción** completa de cada meta anual.

**Salto de línea con punto y coma:** tanto en la descripción breve como en la descripción de las metas por año, si se escribe el carácter **punto y coma (`;`)** en el texto, en la ficha pública se mostrará como **un salto de línea** (cada `;` equivale a un nuevo renglón). Esto permite formatear listas o ítems sin usar el editor HTML. Ejemplo: *"Meta 1; Meta 2; Meta 3"* se verá en tres líneas.

### 6.3 Exportación de medidas

La plataforma permite exportar la información de las medidas climáticas en dos formatos:

**Exportar a PDF:**
- **Medida individual**: desde la ficha de detalle de la medida, hacer clic en el botón de descarga PDF.
- **Múltiples medidas**: desde el listado filtrado, seleccionar las medidas deseadas (hasta 50) y exportarlas en un único archivo PDF consolidado.

**Exportar a CSV:**
- Desde el listado de medidas, seleccionar la opción de exportación CSV.
- El archivo incluye: Línea, Acción, Nombre de la medida, Estado, Pilares y Autoridad responsable.
- Este formato es ideal para importar la información en planillas de cálculo (Excel, Google Sheets) y realizar análisis propios.

### 6.4 Monitoreo y Evaluación (MYE)

El módulo MYE proporciona una visión integral del avance en la implementación de las medidas climáticas.

**Cómo acceder:**
Desde el menú lateral, hacer clic en **"Monitoreo (MYE)"**.

**Información disponible:**
- **Panel de indicadores clave**:
  - Total de medidas registradas.
  - Medidas en implementación.
  - Medidas completadas.
- **Estadísticas de progreso** con gráficos visuales.
- **Categorías de líneas estratégicas** con íconos representativos.
- **Informes de progreso**: documentos descargables que resumen el avance periódico.
- **Documentos metodológicos**: guías sobre la metodología de monitoreo y evaluación, disponibles para descarga.

## 7. Gestión de contenido (Panel del Editor)

Esta sección está dirigida a usuarios con rol de **Editor/Redactor**. Desde el panel de gestión de contenido se crean, editan, traducen y administran las publicaciones del sitio.

### 7.1 Acceder al panel de gestión de contenido

1. Iniciar sesión en la plataforma.
2. Hacer clic en **"Gestión de contenido"** en la barra de navegación superior.
3. Se accederá al panel del editor, donde se muestra el listado de publicaciones.

> **Nota:** Este enlace solo es visible para usuarios con permisos de edición.

### 7.2 Listado de publicaciones

Al acceder al panel de gestión, se muestra el **listado de todas las publicaciones** existentes.

**Funcionalidades disponibles:**
- **Ver todas las publicaciones** con su título, categoría y estado (borrador o publicada).
- **Filtrar por idioma**: seleccionar el idioma para ver las traducciones disponibles o pendientes.
- **Crear una nueva publicación** haciendo clic en el botón correspondiente.
- **Editar** una publicación existente haciendo clic en ella.
- **Traducir** una publicación seleccionando el idioma deseado.

### 7.3 Crear una nueva publicación

> **Requisito:** Solo los editores con permiso para escribir en el idioma por defecto (español) pueden crear publicaciones nuevas.

**Paso a paso:**

1. Desde el listado de publicaciones, hacer clic en **"Nueva publicación"**.
2. Completar los campos del formulario:
   - **Título**: nombre descriptivo de la publicación.
   - **Slug** (opcional): identificador de la URL. Si se deja vacío, se genera automáticamente a partir del título.
   - **Categoría**: seleccionar la sección donde se mostrará la publicación.
   - **Estado**: elegir entre:
     - **Borrador**: la publicación no será visible en el sitio público.
     - **Publicada**: la publicación será visible para todos los usuarios.
   - **Imagen de portada**: subir una imagen representativa (máximo 20 MB, formatos JPG, PNG o SVG).
   - **Descripción breve**: resumen corto que se muestra en las tarjetas de vista previa (máximo 500 caracteres).
   - **Cuerpo del artículo**: contenido principal, redactado en formato Markdown (ver sección 7.5).
   - **Adecuación a perfiles**: asignar un valor de relevancia (0 a 5) para cada perfil temático. Esto determina qué tan relevante es esta publicación para cada perfil.
3. Hacer clic en **"Guardar"** para guardar los cambios, o en **"Guardar y volver al sitio"** para guardar y ver la publicación en el sitio público.

### 7.4 Editar una publicación existente

1. Desde el listado de publicaciones, hacer clic sobre la publicación que se desea editar.
2. Se abrirá el editor con todos los campos de la publicación.
3. Realizar las modificaciones necesarias.
4. Hacer clic en **"Guardar"**.

> **Importante:** Cada vez que se guarda una publicación, el sistema registra automáticamente una nueva versión en el historial, lo que permite volver a versiones anteriores en cualquier momento.

### 7.5 Redacción con Markdown

Las publicaciones se redactan en **Markdown**, un lenguaje de formato ligero que facilita la escritura y la traducción. No es necesario conocer HTML; los atajos más comunes están disponibles mediante los íconos del editor.

**Referencia rápida de Markdown:**

| Elemento | Sintaxis | Resultado |
|----------|----------|-----------|
| Título principal | `# Título` | Encabezado grande |
| Sección | `## Sección` | Encabezado mediano |
| Subsección | `### Subsección` | Encabezado pequeño |
| Negrita | `**texto**` | **texto** |
| Cursiva | `_texto_` | _texto_ |
| Enlace | `[texto](url)` | texto con enlace |
| Lista con viñetas | `* elemento` | - elemento |
| Cita | `> texto` | bloque de cita |
| Línea divisoria | `----------` | línea horizontal |

**Vista previa:** debajo del editor se muestra una **previsualización** del artículo tal como se verá en el sitio. La previsualización se actualiza automáticamente a medida que se escribe.

> **Consejo:** Para necesidades avanzadas de formato (tablas complejas, tamaño de imágenes personalizado), también se puede insertar código HTML directamente dentro del Markdown.

### 7.6 Insertar imágenes en publicaciones

**Imágenes alojadas en la plataforma:**

1. En el editor Markdown, hacer clic en el **botón de imagen** (ícono de imagen en la barra de herramientas del editor).
2. Seleccionar el archivo de imagen desde la computadora.
3. Formatos aceptados: JPG, PNG, SVG.
4. Tamaño máximo: 20 MB.
5. La imagen se sube automáticamente y se inserta el código correspondiente en el editor.

**Imágenes externas:**

Para insertar una imagen alojada en otro sitio web, escribir en el editor:

```markdown
![descripción de la imagen](https://url-de-la-imagen.com/imagen.jpg)
```

> **Nota:** Todas las imágenes de una misma publicación deben tener nombres distintos.

### 7.7 Traducir una publicación

Los editores pueden traducir publicaciones a los idiomas para los cuales tienen permiso.

**Paso a paso:**

1. Desde el listado de publicaciones, identificar la publicación a traducir.
2. Hacer clic en el **idioma destino** de la traducción.
3. Se abrirá el editor de traducción, que muestra:
   - **Panel izquierdo**: el texto original en su idioma fuente (en formato Markdown) para consultar y copiar fragmentos si es necesario.
   - **Panel derecho**: el editor donde se escribe la traducción.
4. Redactar la traducción en el panel derecho.
5. Antes de guardar, el sistema **compara la estructura** (cantidad de secciones e imágenes) del texto original con la traducción para detectar posibles omisiones.
6. Si la verificación detecta diferencias intencionales, se puede desactivar la comprobación desmarcando el botón **"Check diff"**.
7. Hacer clic en **"Guardar"**.

### 7.8 Historial de versiones

Cada publicación mantiene un **historial completo de versiones**. Cada vez que un editor guarda cambios, se crea una nueva versión.

**Cómo consultar el historial:**

1. Desde el listado de publicaciones, seleccionar la publicación.
2. Hacer clic en **"Historial"** (disponible para cada idioma).
3. Se muestra una lista cronológica con:
   - Fecha y hora de cada modificación.
   - Usuario que realizó el cambio.
   - Enlace para ver las diferencias (diff).
   - Enlace para restaurar esa versión.

### 7.9 Restaurar una versión anterior

Si se necesita volver a una versión previa de una publicación:

1. Acceder al **historial de versiones** de la publicación (ver sección 7.8).
2. Hacer clic en **"Ver diferencias"** para comparar la versión seleccionada con la versión actual.
3. En la pantalla de comparación se muestran los cambios lado a lado, resaltando las diferencias.
4. Si se desea volver a esa versión, hacer clic en **"Restaurar"**.
5. La versión restaurada se convierte en la versión actual, y la versión anterior se conserva en el historial.

> **Nota:** Restaurar una versión no elimina ninguna versión del historial. Toda la trazabilidad se mantiene.

### 7.10 Eliminar una publicación

> **Requisito:** Solo los editores con el permiso de eliminación habilitado pueden eliminar publicaciones. Las publicaciones marcadas como **protegidas** no pueden ser eliminadas.

1. Desde el listado de publicaciones, seleccionar la publicación.
2. Hacer clic en **"Eliminar"**.
3. Confirmar la eliminación en la pantalla de confirmación.

> **Advertencia:** Esta acción es irreversible. Se recomienda verificar cuidadosamente antes de eliminar.

## 8. Edición de medidas climáticas

Esta sección está dirigida a editores con el **permiso de medidas** habilitado.

### 8.1 Acceder a la lista de medidas

1. Desde el panel de gestión de contenido, hacer clic en **"Lista de medidas"** en la barra superior.
2. Se muestra la lista de medidas organizadas jerárquicamente:
   - **Líneas estratégicas** (nivel superior)
   - **Líneas de acción** (nivel intermedio)
   - **Medidas** (nivel inferior)

### 8.2 Previsualizar una medida

1. Desde la lista de medidas, hacer clic en el nombre de la medida.
2. Se muestra la **ficha de la medida** con todos sus campos.
3. Los campos en **gris** están actualmente **inactivos**, es decir, no se muestran en el sitio público.
4. Los campos activos se muestran con su contenido actual.

> **Nota:** Desde la previsualización, los administradores pueden hacer clic en **"Admin"** para acceder a la configuración de la medida en el panel de administración, y en **"Activar"** para hacer visible una medida en el sitio público.

### 8.3 Editar los datos de una medida

1. Desde la previsualización de la medida, hacer clic en **"Editar"**.
2. Se abrirá el formulario de edición con los siguientes campos:
   - **Estado de implementación**: seleccionar el estado actual de la medida (En programación, En implementación, Completada, etc.) desde el menú desplegable.
   - **Campos descriptivos**: áreas de texto donde se puede redactar la información detallada de la medida. Los campos disponibles son configurados por el administrador.
3. Los campos en gris son campos **inactivos** y no se mostrarán en el sitio, pero su contenido se conserva.
4. Hacer clic en **"Guardar"** para aplicar los cambios, o **"Cancelar"** para descartarlos.
5. También se puede hacer clic en **"Volver a la lista"** para regresar al listado de medidas.

## 9. Administración de la plataforma

Esta sección está dirigida a usuarios con rol de **Administrador (Staff)** o **Superusuario**. Desde el panel de administración se gestionan todos los aspectos de configuración de la plataforma.

### 9.1 Acceder al panel de administración

1. Iniciar sesión en la plataforma con una cuenta que tenga permisos de administración.
2. Hacer clic en **"Admin"** en la barra de navegación superior.
3. Se accederá al panel de administración, donde se muestran todas las secciones disponibles según los permisos del usuario.

**Secciones principales del panel:**
- **Usuarios**: gestión de cuentas de usuario y permisos.
- **Main**: gestión de contenido (publicaciones, biblioteca, normativas, planes, enlaces, traducciones).
- **Measure**: gestión de medidas climáticas (líneas, acciones, medidas, estados, pilares).

### 9.2 Gestión de usuarios

> **Requisito:** Solo los usuarios del grupo **"full admin"** y los superusuarios pueden gestionar usuarios. Los usuarios del grupo **"manager"** no tienen acceso a esta sección.

**Desde el panel de Usuarios se puede:**
- Ver el listado completo de usuarios registrados.
- Buscar usuarios por nombre o correo electrónico.
- Editar la información y permisos de un usuario existente.
- Crear nuevos usuarios.

### 9.3 Crear un nuevo usuario

1. En el panel de administración, ir a la sección **"Usuarios"**.
2. Hacer clic en **"Agregar usuario"**.
3. Completar los campos obligatorios:
   - **Nombre de usuario**: identificador único.
   - **Contraseña**: establecer una contraseña inicial.
4. Hacer clic en **"Guardar y continuar editando"** para acceder a la configuración completa del usuario.
5. Completar la información adicional según sea necesario:
   - Nombre, apellido, correo electrónico.
   - Perfil, género, ubicación.

### 9.4 Configurar permisos de edición

Para convertir a un usuario en editor/redactor:

1. Dentro de la ficha del usuario, buscar la sección **"Editor Access"** en la parte inferior.
2. Configurar los siguientes permisos:
   - **Todos los idiomas**: si se marca, el editor puede escribir y traducir en todos los idiomas disponibles. Si se desmarca, se deben seleccionar los idiomas específicos.
   - **Idiomas permitidos**: seleccionar los idiomas en los que el editor puede crear y editar contenido.
   - **Puede eliminar**: habilita o deshabilita la capacidad de eliminar publicaciones.
   - **Medidas**: habilita o deshabilita el acceso a la edición de medidas climáticas.
3. Hacer clic en **"Guardar"** para aplicar los cambios.

> **Ejemplo práctico:** Si se necesita un editor que solo traduzca contenido al inglés y no pueda eliminar publicaciones ni editar medidas, se dejaría desmarcado "Todos los idiomas", se seleccionaría "English" en la lista de idiomas, y se dejarían desmarcados "Puede eliminar" y "Medidas".

### 9.5 Designar usuarios como personal administrativo

Para otorgar a un usuario acceso al panel de administración:

1. Dentro de la ficha del usuario, marcar la casilla **"Es staff"**.
2. En la sección de **Grupos**, seleccionar uno de los dos grupos disponibles:
   - **full admin**: acceso completo al panel de administración, incluyendo gestión de usuarios.
   - **manager**: acceso al panel sin poder gestionar usuarios. Puede gestionar categorías, perfiles y otros contenidos.
3. Hacer clic en **"Guardar"**.

> **Importante:** Un usuario puede ser tanto editor como staff al mismo tiempo, lo que le daría acceso tanto al panel de gestión de contenido como al panel de administración.

### 9.6 Gestión de categorías y perfiles temáticos

**Categorías:**
Las categorías organizan las publicaciones en secciones del sitio (Adaptación, Mitigación, etc.).

- Desde el panel de administración, ir a la sección correspondiente de categorías.
- Se pueden crear, editar o desactivar categorías.
- Al crear una nueva categoría, definir su nombre y orden de visualización.

**Perfiles temáticos:**
Los perfiles representan áreas temáticas (Adaptación, Mitigación, Bosques, etc.) y se utilizan para personalizar el contenido recomendado a cada usuario.

- Desde el panel de administración, ir a **"Profiles"**.
- Se pueden crear, editar u ocultar perfiles.
- Cada perfil tiene: código identificador, nombre, imagen representativa, color y URL específica (opcional).
- Si se marca como **"oculto"**, el perfil no estará disponible para selección por parte de los usuarios.

### 9.7 Gestión de la biblioteca

Desde el panel de administración se gestionan los recursos de la biblioteca:

**Libros y documentos:**
1. Ir a la sección **"Books"** en el panel de administración.
2. Hacer clic en **"Agregar"** para crear un nuevo recurso, o seleccionar uno existente para editarlo.
3. Completar los campos:
   - **Año** de publicación.
   - **Categoría** temática.
   - **URL** de acceso externo (si aplica).
   - **Autores**: seleccionar de la lista existente o crear nuevos.
   - **Imagen de portada**: subir una imagen representativa.
   - **Documento**: subir el archivo (PDF o Word, máximo 50 MB).
   - **Formato**: tipo de recurso (Documento, Infografía, etc.).
   - **Opciones adicionales**: marcar si corresponde a comunidad, capacitaciones o ciudadanía.
4. En la sección de **versiones**, agregar el título y la descripción en cada idioma disponible.
5. Hacer clic en **"Guardar"**.

**Autores:**
- Los autores se gestionan desde la sección **"Authors"**.
- Se pueden crear nuevos autores con nombre y apellido.
- Los autores se asocian a los libros al momento de crearlos o editarlos.

**Formatos de libro:**
- Los formatos (Documento, Infografía, etc.) se gestionan desde **"Book Formats"**.

### 9.8 Gestión de normativas

1. Ir a la sección **"Regulations"** en el panel de administración.
2. Hacer clic en **"Agregar"** para crear una nueva normativa, o seleccionar una existente para editarla.
3. Completar los campos:
   - **Tipo**: Ley, Decreto, Resolución o Administrativo.
   - **URL**: enlace al texto completo de la normativa.
   - **Fecha** de publicación.
4. En la sección de **versiones**, agregar el nombre y la descripción en cada idioma.
5. Hacer clic en **"Guardar"**.

### 9.9 Gestión de planes provinciales

1. Ir a la sección **"Plans"** en el panel de administración.
2. Seleccionar el plan a editar o crear uno nuevo.
3. Completar los campos:
   - **Provincia**: seleccionar la provincia correspondiente.
   - **Estado**: estado actual del plan (en elaboración, vigente, etc.).
   - **URL**: enlace al documento del plan.
4. En la sección de **versiones**, completar la información descriptiva en cada idioma.
5. Hacer clic en **"Guardar"**.

### 9.10 Gestión de enlaces

**Enlaces externos:**
1. Ir a la sección **"External Links"** en el panel.
2. Crear o editar un enlace completando: URL, categoría.
3. Agregar versiones con título y descripción en cada idioma.
4. Guardar.

**Enlaces internos:**
- Los enlaces internos se asocian a publicaciones específicas y se gestionan dentro de la ficha de cada publicación.
- Pueden apuntar a una URL directa o a una vista interna del sitio.

### 9.11 Creación y activación de medidas climáticas

> **Nota:** Las medidas se crean y activan desde el panel de administración. Una vez creadas, los editores con permiso de medidas pueden completar y editar sus campos descriptivos desde el panel de gestión de contenido.

**Crear una nueva medida:**
1. Ir a la sección **"Measures"** en el panel de administración.
2. Hacer clic en **"Agregar medida"**.
3. Completar los campos:
   - **Nombre** de la medida.
   - **Código**: identificador alfanumérico.
   - **Línea estratégica** y **línea de acción** correspondientes.
   - **Pilar**: Adaptación, Mitigación o Pérdidas y Daños.
   - **Estado de implementación**: seleccionar el estado actual.
   - **Etiquetas**: categorías adicionales.
   - **Alcance**: Nacional, Regional o A definir.
   - **Objetivos nacionales**: asociar metas nacionales.
4. Configurar la **visibilidad de secciones**:
   - Alcance y estado
   - Período y meta
   - Metas por año
   - Alcance geográfico
   - Riesgos climáticos
5. Marcar **"Activa"** para que la medida sea visible en el sitio público.
6. Hacer clic en **"Guardar"**.

**Metas anuales:**
- Dentro de la ficha de una medida, en la sección **"Measure Year Metas"**, se pueden agregar metas por año.
- Cada meta tiene: **año**, **descripción breve** y **descripción** (detallada).
- En la ficha pública de la medida:
  - La **tarjeta "Metas por año"** muestra solo la **descripción breve**.
  - La sección **Información general → Metas / Años** muestra la **descripción**.
- En ambos campos, el carácter **punto y coma (`;`)** se interpreta como **salto de línea**: el texto se verá en varios renglones según dónde se coloquen los `;`.

### 9.12 Gestión de líneas estratégicas y acciones

**Líneas estratégicas:**
1. Ir a **"Lines"** en el panel de administración.
2. Crear o editar una línea completando: nombre, descripción, color, ícono, categoría.

**Categorías de líneas:**
- Se gestionan desde **"Line Categories"** y agrupan las líneas estratégicas.

**Líneas de acción:**
1. Ir a **"Actions"** en el panel.
2. Crear o editar una acción completando: nombre, descripción, color, línea estratégica asociada.

**Estados de implementación:**
- Se gestionan desde **"Implementation Status"**.
- Cada estado tiene: nombre, orden de visualización, color y categoría de tarjeta.

**Pilares y etiquetas:**
- **Pilares** (Adaptación, Mitigación, Pérdidas y Daños) se gestionan desde **"Pilars"**.
- **Etiquetas** se gestionan desde **"Labels"**.

### 9.13 Traducciones de interfaz

La plataforma permite traducir los textos estáticos de la interfaz (botones, menús, mensajes) a múltiples idiomas.

1. Ir a la sección **"Static Trans"** en el panel de administración.
2. Cada elemento de traducción tiene un **texto base en español** y versiones en otros idiomas.
3. Para agregar o editar una traducción:
   - Seleccionar el elemento.
   - En la sección de versiones, completar la traducción para cada idioma.
   - Guardar.

## 10. Preguntas frecuentes

### Acceso y autenticación

**P: Olvidé mi contraseña, cómo ingreso al sistema?**
R: Actualmente la plataforma utiliza autenticación por correo electrónico y contraseña. Si olvidaste tu contraseña, contactá al administrador del sistema para que pueda asistirte en el restablecimiento de acceso.

**P: Puedo cambiar mi correo electrónico?**
R: No. El correo electrónico es el identificador único de cada cuenta y no se puede modificar desde el perfil. Para cambiar el correo, contactar al administrador.

### Gestión de contenido

**P: No veo el enlace "Gestión de contenido" en la barra superior.**
R: Este enlace solo es visible para usuarios con permisos de edición. Contactar al administrador para solicitar los permisos correspondientes.

**P: Puedo crear publicaciones en otros idiomas además de español?**
R: Las publicaciones se crean inicialmente en español (idioma por defecto). Luego se pueden **traducir** a otros idiomas. Solo los editores con permiso para el idioma por defecto pueden crear publicaciones nuevas; los demás editores solo pueden traducir.

**P: Eliminé una publicación por error. Se puede recuperar?**
R: No. La eliminación de publicaciones es una acción irreversible. Se recomienda verificar cuidadosamente antes de confirmar la eliminación.

**P: Se puede recuperar una versión anterior de una publicación?**
R: Sí. Desde el historial de versiones se puede restaurar cualquier versión previa. La restauración no elimina ninguna versión del historial.

### Medidas climáticas

**P: No puedo crear medidas desde el panel de gestión de contenido.**
R: Las medidas se crean desde el **panel de administración** (acceso de Staff). Desde el panel de gestión de contenido solo se pueden editar los campos descriptivos de medidas ya existentes.

**P: Qué significan los campos en gris en la previsualización de una medida?**
R: Los campos en gris son campos **inactivos**, lo que significa que no se muestran en el sitio público. Su contenido se conserva pero no es visible para los usuarios del portal.

**P: Cómo hago visible una medida en el sitio público?**
R: Desde el panel de administración, editar la medida y marcar la casilla **"Activa"**. Solo los administradores pueden activar medidas.

### Administración

**P: Cuál es la diferencia entre los grupos "full admin" y "manager"?**
R: Los usuarios **full admin** tienen acceso completo al panel de administración, incluyendo la gestión de otros usuarios. Los **manager** pueden gestionar categorías, perfiles y contenido, pero **no pueden crear ni editar otros usuarios**.

**P: Un usuario puede ser editor y administrador al mismo tiempo?**
R: Sí. Un usuario puede tener permisos de edición (Editor Access) y permisos de administración (Staff) simultáneamente, lo que le da acceso tanto al panel de gestión de contenido como al panel de administración.

## 11. Glosario

| Término | Definición |
|---------|-----------|
| **Borrador** | Estado de una publicación que no es visible en el sitio público. Permite trabajar en el contenido antes de publicarlo. |
| **Categoría** | Clasificación temática de las publicaciones (Adaptación, Mitigación, etc.). |
| **Diff** | Comparación visual entre dos versiones de un contenido, mostrando los cambios realizados. |
| **Editor / Redactor** | Usuario con permisos para crear, editar y traducir publicaciones. |
| **Estado de implementación** | Etapa actual de una medida climática (En programación, En implementación, Completada, etc.). |
| **Full admin** | Grupo de administradores con acceso completo, incluyendo gestión de usuarios. |
| **Línea de acción** | Conjunto de medidas dentro de una línea estratégica, que agrupan acciones concretas. |
| **Línea estratégica** | Eje temático principal que agrupa líneas de acción y medidas climáticas. |
| **Manager** | Grupo de administradores con acceso al panel sin poder gestionar usuarios. |
| **Markdown** | Lenguaje de formato ligero utilizado para redactar publicaciones. |
| **Medida climática** | Acción concreta de implementación dentro de la estrategia nacional de cambio climático. |
| **Meta anual** | Objetivo cuantificable establecido para una medida climática en un año específico. |
| **MYE** | Monitoreo y Evaluación. Módulo para dar seguimiento al avance de las medidas climáticas. |
| **Perfil temático** | Área de interés del usuario (Adaptación, Mitigación, Bosques, etc.) que personaliza el contenido recomendado. |
| **Pilar** | Clasificación principal de las medidas: Adaptación, Mitigación o Pérdidas y Daños. |
| **Publicación** | Artículo o noticia del sitio, incluyendo su título, cuerpo, imágenes y metadatos. |
| **Slug** | Identificador amigable de la URL de una publicación, generado a partir del título. |
| **Staff** | Usuario con acceso al panel de administración de la plataforma. |
| **Superusuario** | Usuario con acceso completo a todas las funcionalidades del sistema. |
| **Versión** | Instantánea del estado de una publicación en un momento determinado, que se registra automáticamente al guardar. |
